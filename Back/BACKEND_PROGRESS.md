## Условия включения и границы

- **OpenAI**: адаптер и fallback готовы, платные вызовы по умолчанию выключены. Нужны актуальный серверный ключ, выбранные модели и проверенные цены. Бюджет $40 относится к журналу этой платформы. Реальные оплачиваемые запросы при разработке не выполнялись.
- **OIDC/LMS/HRIS/messenger/IT-HR**: backend-адаптеры готовы; для подключения нужны реальный провайдер/relay, секреты, ID mappings и разрешения организации. Провайдеры недоступны по умолчанию. Заявки без внешнего ID не объявляются созданными.
- **Путеводитель**: поставляются 15 явно синтетических demo-статей (5 ситуаций × 3 языка). Реальные регламенты, владельцы, контакты и SLA утверждает организация. Неподтверждённые контакты не выдумываются.
- **Награды**: механизм готов; выдача требует включения утверждённых правил и наполнения каталога администратором.
- **Тренды/ROI**: расчёты готовы; временные ряды требуют нескольких дат оценки, финансовый результат — утверждённых затрат/выгод.
- **GUIDE-X-03**: SQL full-text + aliases работает сразу. Embeddings-адаптер и индекс готовы. Администратор сначала индексирует утверждённые статьи и сравнивает recall@3 с SQL минимум на 10 разных вопросах. Включение разрешено только при результате не хуже SQL и ≥0.7. Изменение статей, индекса или модели требует повторной оценки. До активации и при ошибках используется SQL. Реальная оценка на выбранной модели при разработке не оплачивалась; тесты используют mock-провайдер.
- **PRED-02**: вероятность оттока не рассчитывается без размеченных исходов и оценки качества/справедливости; API возвращает явную недоступность. Сигнал участия PRED-01 уже работает.
- **AI-X-01 / NVIDIA**: отложены пользователем. NIM не разворачивается, сравнение двух провайдеров пока не проводится.
- **INT-06 / UI I18N / доступность с клавиатуры**: это работа `Front/`. Backend не сохраняет персональные данные в браузере и отдаёт `Cache-Control:no-store`.

Фронтенд подключается по [README контрактов](contracts/README.md), точные DTO/методы — [OpenAPI](contracts/openapi.yaml). Итоги проверок и порядок запуска — [Back/README](README.md), восстановление — [OPERATIONS](OPERATIONS.md).

## Приёмка 2026-09-23

- 110 тестов прошли на Node.js 24.19.0 с PostgreSQL 17; пропусков нет.
- TypeScript и Docker-сборка прошли; применены 8 миграций к существующей локальной БД.
- API готов, worker запущен, readiness через frontend proxy отвечает успешно.
- Backup/restore проверены на отдельной временной БД, включая откат при ошибке. Рабочая БД не сбрасывалась.
- GitHub Actions не смог запустить задания: GitHub сообщил о блокировке аккаунта из-за биллинга. Удалённый CI не считается пройденным; требуется действие владельца аккаунта/организации.
- Внешние AI-запросы и отправки в корпоративные системы в ходе проверки не выполнялись.
