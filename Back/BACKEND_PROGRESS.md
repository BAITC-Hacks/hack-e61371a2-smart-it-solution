# Backend: полный объём

Текущая реализация расширяет основу этапов 1–2. `Front/**` принадлежит тиммейту.

| Блок | Ответственность | Статус |
| --- | --- | --- |
| Карьерное ядро | Навыки, цели, каталог, участие, прогресс, рекомендации | В разработке |
| Путеводитель / ИИ | Версии знаний, контакты, поиск, помощник, бюджет OpenAI | В разработке |
| Развитие / мотивация | Планы, симуляции, менторы, задания, награды | В разработке |
| HR / управление | Агрегаты, роли, аудит, переводы, импорты | В разработке |
| Интеграции | Уведомления, календарь, OIDC, webhooks, адаптер IT/HR | В разработке |
| Приёмка | Миграции, PostgreSQL-тесты, API-контракт, Docker | После сборки модулей |

Внешние подключения отключены до настройки организацией. Неподключённый сервис возвращает явный статус, а не фиктивный результат. NVIDIA остаётся отложенной по решению пользователя. Прогноз оттока не рассчитывается без размеченных исходов и проверки качества; ROI требует утверждённых финансовых данных. Это зависимости функций из исходного ТЗ.
