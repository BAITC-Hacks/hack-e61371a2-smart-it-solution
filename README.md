## О треке

В предоставленном техническом задании Halyk Bank для HackAlem.ai поставлена задача **«AI для корпоративных продуктов»**. Мы выбрали кейс **Career Quest** — AI-навигатор развития сотрудника.

## Кейс: Career Quest

Сотрудники получают разрозненные уведомления об обучении и других HR-активностях, но часто не видят, как эти действия помогают профессиональному росту. **Career Quest** должен сделать траекторию развития понятной и предлагать следующий полезный шаг с объяснением выбора.

Согласно техническому заданию, решение должно:

- показывать сотруднику профиль, навыки, текущий грейд и карьерную траекторию;
- рекомендовать **1–3 активности**, учитывая грейд, разрывы по навыкам, историю участия и требования следующего уровня;
- объяснять каждую рекомендацию и обновлять прогресс после выполнения активности;
- давать HR обзор навыков, которым требуется развитие, и участия сотрудников в активностях.

Сейчас реализована основа этапов 1–2: API, импорт данных, вход, права доступа и стартовый интерфейс. Карьерные расчёты и AI-рекомендации относятся к следующим этапам.

Подробное техническое задание и проектная архитектура: [TECH_SPEC.md](TECH_SPEC.md).

## Запуск локальной демонстрации

Нужны Docker Engine и Compose. Согласованный ориентир Docker — 29.1.3; локальная проверка проведена на установленном 29.6.2 без замены системного Docker. В контейнерах Node.js 24.19.0, PostgreSQL 17. Системный Node для Docker-запуска не нужен.

```bash
docker compose up -d --build --wait
```

Открыть **http://localhost:8080**. Четыре демо-роли доступны на странице входа без пароля. Это локальная среда с синтетическими профилями. Порты привязаны к loopback. По умолчанию платные AI-вызовы и внешние доставки выключены; NVIDIA Brev подключается отдельной конфигурацией: [инструкция запуска модели и туннеля](Back/NVIDIA_BREV_SETUP.md).

- Сотрудник — только свой профиль и свою историю в статистике.
- Руководитель — себя и прямых подчинённых.
- HR — профили организации.
- Администратор — профили и API импорта с предпросмотром.

Миграции и первый импорт выполняются автоматически. Повторный запуск не дублирует данные. Стартовый интерфейс содержит вход, сводку и страницу прав; остальные страницы делает frontend-направление согласно TEAM_WORK.md. Backend уже предоставляет карьерные сценарии, планы, HR, путеводитель, помощника, администрирование и адаптеры интеграций. Подробности и внешние зависимости — [Back/README.md](Back/README.md).

```bash
docker compose ps
docker compose logs --tail 50 back
docker compose stop
```

`docker compose down` удаляет контейнеры, сохраняя volume БД. Не добавляйте `-v`, если хотите сохранить импортированные данные.

- [Backend: запуск, тесты и обычные аккаунты](Back/README.md).
