# Career Quest — Front

Клиентское приложение для сотрудника, HR и администратора. Сейчас здесь зафиксированы границы разработки и конфигурация; код приложения и команды запуска появятся в отдельном PR.

## Стек

React 19.2, TypeScript 5.9, Vite 7, Tailwind CSS 4, Radix UI в стиле shadcn, `class-variance-authority`, `tailwind-merge`, `wouter`.

## Ответственность

- Общий интерфейс, навигация, адаптивность, доступность, переключение языка.
- Кабинет сотрудника: профиль, навыки, цель, траектория, история и рекомендации.
- Каталог активностей, запись и отображение результата завершения.
- Панель HR: дефициты навыков, участие, сотрудники без следующего шага.
- Путеводитель: рабочие ситуации, статьи, контакты и маршрут обращения.
- Чат с ИИ: сообщения, ссылки на источники, состояния ожидания и недоступности.
- Администрирование: импорт, статьи, контакты и мероприятия с учётом прав.

Сервер проверяет права и рассчитывает навыки, прогресс и рекомендации. Клиент отображает результат и отправляет действия пользователя через `/api/v1`.

## Планируемая структура

```text
Front/
  src/
    app/             Инициализация, маршруты, общие providers
    pages/           Страницы сотрудника, HR, администратора
    features/        Цели, активности, рекомендации, путеводитель, чат
    components/ui/   Общие компоненты на Radix
    api/             HTTP-клиент и DTO, полученные из контракта Back
    i18n/            Словари RU/KZ/EN
    styles/          Tailwind и дизайн-токены
  public/            Публичные статические ресурсы
  tests/             Проверки UI и пользовательских сценариев
  .env.example       Только публичные настройки
```

Это целевая структура; каталоги исходников создаются вместе с кодом. `Front` будет иметь собственные `package.json`, lock-файл, сборку и Dockerfile.

## Конфигурация

Будущий Vite-клиент использует `VITE_API_BASE_URL=/api/v1`. Для локальной разработки Vite proxy будет направлять `/api` на `http://localhost:3001`; в Docker — на адрес API в сети Compose. В production запросы направляет reverse proxy с того же origin.

Все `VITE_*` значения доступны пользователю браузера. OpenAI/NVIDIA-ключи и `DATABASE_URL` хранятся исключительно в `Back`.
